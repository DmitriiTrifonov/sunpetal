# Закрытие задачи после ручной проверки

Папка `docs/qa/` — только то, что автору ещё предстоит проверить. Проверил — файлов задачи там быть не должно.

1. Карточка: `python3 tools/kanban/kanban.py move K-NNN done`, затем `kanban.py render`. Если карточка уже в `done` — сказать об этом, остальные шаги всё равно выполнить.
2. Удалить `docs/qa/K-NNN.md` и все парные файлы `docs/qa/K-NNN-*.md` (списки и т. п.): `git rm`, если файл в git.
3. Убрать строку `| K-NNN | … |` из таблицы «Состав» в `docs/qa/README.md`.
4. Время: если в `tools/roadmap/timelog.csv` есть незакрытая запись по K-NNN — `python3 tools/roadmap/timelog.py end K-NNN "проверено автором"`; нет записи — ничего не придумывать.
5. Артефакты (`artifacts/k-nnn/` и т. п.) не трогать без слова автора.
6. Коммит только по просьбе; если просят, коммитить в одном коммите карточку, удаление и README. Трейлер — по `close-step`.
7. Одно сообщение автору: что удалено, что осталось в `docs/qa`.
