# Закрытие шага

1. Результат КТ — в журнал документа плана (числа до/после, что не достигнуто и почему), чекбокс `[x]` (`[~]` — если сделана часть, с названием остатка).
2. Раздел «Состояние» — коротко в `AGENTS.md` (3–5 строк), подробности в `docs/STATUS.md`, а не наоборот.
3. Тесты: `cargo test -p sunpetal-app --release --lib` (приложение); для рантайма — скилл `sunpetal-build-test`, для GPU — `gpu-parity`.
4. Коммит только по просьбе пользователя; пуш только по просьбе; CI после пуша смотреть только по просьбе или если менялся код сборки и тестов.
5. Конец сообщения коммита:

```
Co-Authored-By: <имя нейросети, которая делает коммит> <её noreply-адрес>
Claude-Session: <ссылка на сессию, если дана в системной подсказке>
```

6. Новые баги — в `docs/BUGS.md` (`B-NN`, где/причина/проверка/статус), снимки — в `artifacts/`.
