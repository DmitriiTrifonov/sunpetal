# Пакет на проверку

Автора не ждём: вопрос идёт в пакет, карточка — в «Проверку», сам берёшь следующую (`docs/AUTONOMY.md`).

## Подготовка
1. Сначала лестница: авто → глаза агента (сам снял кадр, посмотрел, пара «до/после») → автор по картинке → автор в игре. Автору — только то, что ниже проверить нельзя; причину записать в `note`.
2. `artifacts/review/ГГГГ-ММ-ДД/items.json`, не больше 10 пунктов. Пункт: `id`, `card`, `question` (ответ в один щелчок), `note`, `images` (пара до/после, только окно приложения, абсолютные пути), `options` (по умолчанию да/нет/пропустить), при нестандартных вариантах — `good`/`bad`.
3. Кадр должен быть свежим: пересобрать пакет картинок/модели после последней правки, иначе автор оценит устаревший снимок (так вышло с цветком вазы 2026-11-13).
4. Пункты «в игре» — туром по закладкам; закладку у автора просить одной фразой, не прохождением.

## Сборка и выдача
`python3 tools/auto/review.py serve artifacts/review/ДАТА` (страница `localhost:8765`). Сервер — твой процесс: можно гасить сразу, как автор прислал ответы. Игру автора не трогать.

## Разбор ответов
`python3 tools/auto/review.py apply artifacts/review/ДАТА` — список действий:
- `close` → скилл `close-qa`;
- `bug` → скилл `bug-task` с тем же кадром. Сначала проверь, не устарел ли кадр (см. выше) — ответ «нет» мог относиться к уже исправленному;
- `next` → пункт в следующий пакет;
- `pending` → ждёт; `decide` → вариант без толкования, реши сам по смыслу вопроса.
Итог ответов записать в `docs/NEXT.md`. Замечание автора, объясняющее наблюдение, — в память проекта.
