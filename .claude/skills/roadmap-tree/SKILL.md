# Дерево оставшихся работ

Источник правды — `tools/roadmap/roadmap.json` (дерево с весами, правится вручную по планам). Генератор `tools/roadmap/build.py` (только stdlib) собирает из него `docs/ROADMAP.html`. HTML руками не править.

## Пересоздание

1. Прочитать открытые пункты (`[ ]`, `[~]`) в `docs/PLAN.md`, `docs/SINGLE-SCREEN.md`, `docs/2D-UPSCALE.md`, `docs/BUGS.md` (раздел «Открытые»), «Недоделки» в `docs/STATUS.md`. Быстрый обзор: `grep -n '\[ \]\|\[~\]' docs/PLAN.md docs/SINGLE-SCREEN.md docs/2D-UPSCALE.md`.
2. Сверить с `roadmap.json`:
   - закрытый шаг (`[x]`, баг закрыт) — перенести лист из `roadmap.json` в `tools/roadmap/done.json` (ветка с тем же названием; вес оставить, `n` — дата закрытия; `id` — как в замере времени). Вкладка «Всё дерево» собирает сделанное оттуда, открытое — из `roadmap.json`; статус «в работе» ставится сам, если есть открытая запись `timelog.csv` с `id` листа;
   - новый открытый пункт — добавить лист в нужную ветку (или новую ветку);
   - шаг стал частично сделан — `"p": true`, поправить `n`;
   - пункт, закрытый по факту, но с незакрытым чекбоксом, — метка `close`.
3. Обновить поле `updated` датой правки.
3а. Обновить историю из git: `python3 tools/roadmap/timelog.py history` (правила привязки коммитов к этапам — `tools/roadmap/history-rules.json`; нераспознанные темы коммитов печатаются — дописать правило). Живые замеры (`timelog.csv`) команда не трогает.
4. `python3 tools/roadmap/build.py` — при ошибке схемы печатает путь узла и причину. Результат: `docs/ROADMAP.html`.
5. Открыть файл (`open docs/ROADMAP.html`) только если пользователь просит посмотреть. Коммитить только по просьбе (файл — документ, игровых данных в нём нет).

## Схема узла

- Ветка: `{"t": название, "s": источник, "c": [узлы]}`; вес ветки считается как сумма листьев.
- Лист: `{"t": название, "w": вес, "k": [метки], "p": true, "s": источник, "n": пояснение}`.
- Вес `w` — только из `1, 2, 3, 5, 8, 13`: 1 — до часа; 2 — пара часов; 3 — одна сессия; 5 — несколько сессий; 8 — большая задача с разведкой и риском (в том числе когда нужен паритет GPU/софт); 13 — эпик.
- Метки `k`: `manual` — нужна ручная проверка (окно, телефон); `author` — ждёт решения или слова автора; `deferred` — отложено решением автора; `close` — достаточно закрыть чекбокс или поправить документ. Автономная работа = лист без `manual`, `author`, `deferred`.

## Как ставить вес

Оценивать по объёму и риску, а не по важности: разведка в `sunpetal-debug` без кода — 1–3; новая функция с тестом на кадрах — 3–5; переделка рендерера или шов C↔Rust — 8; новый формат плюс подмена данных игры — 8–13. Ручная проверка добавляет шаг, но вес не меняет. Не придумывать: если непонятно, что в пункте, прочитать его раздел плана.

## Что не трогать

Пункты из «Не трогать без слова автора» (`AGENTS.md`) оставлять с меткой `author`.

## Замеры времени

- Живые: `tools/roadmap/timelog.py start|end|open|report` (когда ставить — скилл `plan-steps`, п. 9). Если у листа дерева есть `id`, равный `id` замера, на листе появляется «N ч факт»; когда есть хотя бы один такой лист, считается «часов на единицу веса» — по нему сверять шкалу весов.
- История из git: коммит «владеет» интервалом после предыдущего коммита (≤ 2 ч, иначе условные 0,5 ч — `--cap`, `--lead`). Это нижняя оценка активной работы: коммиты идут пачками, разговор без коммитов не виден, сон и перерывы отсекаются. Старт этапа — начало интервала его первого коммита, конец — его последний коммит.
- `history.csv` пересобирается целиком, `timelog.csv` — только дописывается.

- Калибровка «часов на единицу веса» считается по этапам, где у листьев есть и `w`, и замер с тем же `id` (сумма часов / сумма весов). Веса сделанного, поставленные задним числом, — оценки; со временем заменять их по живым замерам.
- Страница `docs/ROADMAP.html` — три вкладки: «Осталось» (открытое с весами), «Всё дерево» (сделано, в работе, частично, открыто, фильтры и поиск), «Граф» (узлы-связи, ветки сворачиваются кликом, колесо — масштаб, перетаскивание — сдвиг; размер узла — вес, кольцо ветки — доля сделанного). Граф рисуется на JS из тех же данных, ничего отдельного обновлять не нужно.
