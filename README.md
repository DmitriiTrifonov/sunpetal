# Sunpetal

Статический рекомп DS-версии Flower, Sun, and Rain в нативное приложение (iOS, Android, macOS, Linux, Windows). Рантайм на Rust.

**Статус:** рабочий прототип, [подробности](docs/STATUS.md). Игра идёт в окне на macOS и на Android (проверено на Galaxy Z Flip7): 2D, 3D (внутреннее разрешение до 8×, многопоточный рендер), звук, меню настроек, эффекты (CRT, сетка LCD, цветокоррекция), пакеты замены текстур (в том числе из PS2-версии), экранные кнопки для телефона, геймпад. ROM, образы и извлечённые данные в репозиторий не входят: игра собирается из собственного дампа пользователя, готовых сборок с игрой нет, см. [сборка](docs/BUILD.md).

- [Как собрать из своего ROM](docs/BUILD.md)
- Данные игры: `sunpetal-build` собирает `sunpetal.data` из вашего ROM (и по желанию PS2-образа и перевода), `sunpetal-check` проверяет его; сам файл содержит данные игры и не распространяется, перевод идёт отдельной дельтой без текста оригинала и под своей лицензией, см. `NOTICE`
