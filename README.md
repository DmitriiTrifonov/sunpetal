# Sunpetal

Статический рекомп DS-версии Flower, Sun, and Rain в нативное приложение (iOS, Android, macOS, Linux, Windows). Рантайм на Rust.

**Статус:** рабочий прототип, [подробности](docs/STATUS.md). Рекомпилированная игра исполняется на Rust-рантайме безголово: логотипы, меню, вступительная сцена, 2D, 3D и звук (PNG и WAV). Есть окно с GPU, звуком, клавиатурой, геймпадом и мышью (`sunpetal-app`). Ром, образы и извлечённые данные в репозиторий не входят: игра запускается из собственного дампа пользователя.
