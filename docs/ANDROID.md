# Android

Состояние на 2026-10-24: собирается `apk` (arm64). Проверено на Galaxy Z Flip7 (Android 16): устанавливается, выбор ROM работает, игра идёт на 60 кадрах в секунду (кадр считается за ~8 мс при 3D 1×), кнопки рисуются. Не проверено: звук, играбельность кнопками, возврат из фона после исправления, 3D на масштабе 2 и выше.

**Урок.** Первая версия шла по 1 кадру в секунду из-за ошибки в рантайме, не связанной с Android: чтение картриджа маскировалось размером образа, верным только для степени двойки (ROM из проекта перевода 57 МБ). Исправлено (`chip_mask` в `cart.rs`). Строка скорости над картинкой включается флажком в меню («Показывать скорость»); при остановке игры причина всегда видна на экране.

## Сборка

Нужны: JDK (`javac`), Android SDK (платформа 26+, build-tools), NDK r27, `cargo install cargo-ndk`, `rustup target add aarch64-linux-android`.

```sh
tools/android/build-apk.sh        # build/android/sunpetal.apk, подпись отладочным ключом
adb install -r build/android/sunpetal.apk
# ром выбирается на телефоне при первом запуске; можно и положить вручную:
adb push rom.nds /sdcard/Android/data/org.sunpetal.app/files/rom.nds
```

Скрипт: `cargo ndk` собирает `libsunpetal_app.so` (приложение как `cdylib`, точка входа `android_main`, `NativeActivity` из `winit`), `aapt2` пакует манифест (`tools/android/AndroidManifest.xml`), `zipalign`, `apksigner`. Сгенерированный C собирается clang из NDK через `cc` в `build.rs`.

Логи (всё, что приложение пишет в stderr): `adb logcat -s sunpetal`.

## Как устроено

- ROM: при первом запуске `PickerActivity` (Java, `tools/android/java`) открывает системный выбор файла (`ACTION_OPEN_DOCUMENT`, разрешения не нужны), копирует выбранный файл в `rom.nds` и запускает игру (`NativeActivity`). Файл лежит в `Android/data/org.sunpetal.app/files/` (общий накопитель, достаётся через `adb push` и файловый менеджер на Android до 11). Сохранения кладутся рядом; настройки в приватной папке приложения.
- Картинка: те же `wgpu` и `egui`, что на десктопе. Звук: `cpal` (AAudio). Касание нижнего экрана = стилус.
- Экранные кнопки (`touchpad.rs`): полоса под экранами (не меньше 28% и не больше 50% высоты окна), в ней крестовина, A/B/X/Y, L и R, Select и Start, кнопка MENU. Мультитач; палец, скользящий с кнопки на кнопку, нажимает вторую. Рисуются через `egui` поверх картинки. Игрой можно управлять одним стилусом (касанием нижнего экрана), поэтому кнопки необязательны: настройка «Кнопки на экране»: на телефоне (по умолчанию) / всегда / никогда. Без кнопок экраны занимают всё окно, а меню открывает маленькая кнопка «≡» в правом верхнем углу (на Android она остаётся всегда, когда кнопок нет), рядом с ней кнопка ускорения «»» (нажатие включает и выключает перемотку; пункт «Кнопка ускорения» в разделе «Отладка» меню, по умолчанию включён) и ещё левее кнопка пропуска (значок «играть и стоп»): нажатие включает перемотку на полной скорости, которая сама заканчивается, когда картинка секунду не меняется (игра ждёт игрока: диалог, выбор) или через пять минут игрового времени; повторное нажатие отменяет, пока идёт, значок подсвечен, звук отключён, а экран плавно темнеет до чёрного (перемотку не видно) и так же плавно возвращается. На десктопе то же на F7. Пункт «Кнопка пропуска» в «Отладке» меню. Вступительная поездка и другие ролики пропускаются так же; на DS Start и A их не пропускают (`input.touch_controls` в `config.toml`); на десктопе включается для проверки через `[input] touch_controls = "on"`.
- Внутреннее разрешение 3D по умолчанию 1× (рендер программный и однопоточный).

## Свайп для диска

В головоломке с поворотным диском (замок чемоданчика) на DS диск крутят стилусом по кругу; пальцем по прямой угол прыгает. `dial.rs`: пока на нижнем экране узнана эта сцена (цвета в 12 точках, не зависят от эффектов), касание кольца диска (не средней кнопки) превращается в движение «пера» по окружности: сдвиг пальца вправо/влево поворачивает диск (вправо по часовой). По умолчанию выключено (по решению пользователя диск крутится по кругу, как на DS). Меню → Управление: флажок и чувствительность (минус меняет направление). Геометрия диска (центр 153,95, радиус 79) снята со скриншота русской версии; на других языках раскладка та же. Подгонка: чувствительность по устройству, при необходимости направление.

## Не сделано

- Положение и размеры кнопок подобраны по расчёту (тест на непересечение для нескольких размеров окна), не по ощущению в руке; нужны правки после проверки на телефоне. Нет вибрации, нет настройки прозрачности и размера. Геймпад по Bluetooth: `gilrs` на Android не работает.
- Сменить ROM из приложения (сейчас: очистить данные приложения или удалить `rom.nds`). Проверка, что выбран именно DS-ROM, только по размеру.
- Сообщение на экране, если ROM не найден (сейчас приложение просто закрывается, причина в logcat).
- Меню настроек под палец, ориентация, фоновые режимы, иконка, подпись для релиза, armeabi-v7a и x86_64.
