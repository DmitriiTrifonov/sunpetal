# Рефакторинг `App` в sunpetal-app

План разбивки раздутого `crates/sunpetal-app/src/lib.rs` (1863 строки на коммите `3dca27c`). Правила плана — скилл `plan-steps`. Поведение приложения **не меняется**: это перенос и группировка, новых функций нет.

## Зачем

Листовые модули app (`audio`, `effects`, `fonts`, `post`, `rec`, `dial`, `layout`) разделены нормально. Проблемы в корне:

| Что | Где | Чем плохо |
|---|---|---|
| `App`: 60 полей без группировки | `lib.rs:154` | любой метод видит и меняет всё |
| `impl App` ≈ 700 строк, `redraw` ≈ 300 строк | `lib.rs:255`, `:660` | не читается и не тестируется кусками |
| `ApplicationHandler` ≈ 250 строк | `lib.rs:963` | `window_event` ≈ 230 строк в одной функции |
| Обратные зависимости на корень | `script.rs` → `crate::prepare/stop_machine/apply_variants`; `pad.rs` → `crate::bit/pad_button` | подмодуль зависит от родителя |
| Цикл `config` ↔ `layout` | `config.rs`, `layout.rs` | связность выше нужной |
| Тесты и `mod android` посреди файла | `lib.rs:1473…1840` | файл рос без выделения модулей |
| `prepare` ≈ 190 строк, `desktop_main` ≈ 120 строк | `lib.rs:1264`, `:1581` | разбор опций, запуск и сборка состояния вперемешку |
| `main.rs.bak` | `src/`, отслеживается git | мусор |

Цель: `lib.rs` до ≈ 400 строк (объявления модулей, `run`, публичный API), `App` разложен на группы состояния, ни один подмодуль не ходит в `crate::<корень>`.

## Правила выполнения

- Один шаг — один коммит (по просьбе пользователя), откат шага не задевает соседние.
- Флага не нужно: чистый перенос. Риск ограничен тем, что каждый шаг проверяется тестами до коммита.
- Поля `App` приватные в корне, значит модули-потомки корня (`mod xxx;` в `lib.rs`) видят их без правки видимости. Поэтому `impl App` можно раскладывать по файлам до группировки полей.
- Код под `cfg(android)` на macOS не собирается: шаги, которые его трогают, помечены, их КТ — `cargo check --target aarch64-linux-android` (если нет тулчейна — минимальные правки и ручная проверка пользователем).
- Игру пользователя не перезапускать (`window-restart` только по его слову). Все авто-КТ безголовые.
- Общая КТ каждого шага: `cargo test -p sunpetal-app --release --lib` зелёный, число тестов не упало.
