# Чек-лист поведения DS-версии

Источник: гайд «FSR Version Differences» (speedrun.com, AdrianVG, сравнение PS2 JP и DS). Пункты про DS проверяем в приложении руками; отметка `[x]` значит «совпадает с оригиналом».

## Титул и меню

- [x] Логотипы → вступительный ролик → Press Start.
- [x] Рамка Press Start на нижнем экране мигает и висит всё время сцены.
- [x] Один Start/касание на титуле ведёт сразу в главное меню (не перематывает сцену).
- [x] Бездействие на Press Start возвращает к логотипам (ролик не запускается).
- [x] Три слота сохранения; копирование, удаление и загрузка работают.
- [x] У слота есть счётчик процента прохождения.
- [x] Параметры слота: одна опция, лицо (портрет) справа/слева.
- [x] Список запросов: по три на странице; «Next» идёт по кругу, «Back» возвращает в меню.
- [x] Вкладка Movie: подменю (Anata no Tame Ni 2, Welcome II после открытия), ролики не зацикливаются.

## Катарина (Catherine) и игровой процесс

- [x] Катарина открывается в любой момент касанием значка или кнопкой Y.
- [x] Вкладки: путеводитель, заметки пером, Goods, четвёртая — Jack при пазле, Save вне пазла.
- [x] Сохранение в любой момент через Катарину (Remy/Koshi: через телефон).
- [x] Джек вставляется вручную: касанием или удержанием A (клавиша Z) со стрелками; выбор джека стрелками.
- [x] Числа в пазлах меняются и вверх/вниз, и влево/вправо; выбор джека замкнут по кругу.
- [x] Путеводитель: текст поверх полных страниц, переключатель текста, быстрое меню страниц; всегда открывается с первой страницы.
- [x] Карта на нижнем экране при ходьбе; счётчик шагов.
- [x] Всей игрой можно управлять стилусом.
- [x] После первого прохождения запроса автосохранение; при повторном — экран Edo и автосохранение, затем логотипы.

## Сцены (для сверки картинки)

- [x] R00: парковка, событие Lost and Found (три предмета проверены), Welcome II.
- [ ] R02: крыша, бассейн квадратный.
- [ ] R09: вывеска отеля крутится быстро; нет бутылок на стойке закусочной.
- [ ] R11: загрузка при входе в маяк.
- [ ] R14: в холле после радио-пазлов играет Gymnopédie.
- [ ] R18: титры, эпилог.

## Известные расхождения PS2/DS (не баги текстур)

Меню, Катарина, экран сохранения, ролики Welcome и клип на DS нарисованы заново; в локациях другой масштаб, часть пальм и мелких предметов убрана. Для файла данных эти текстуры пары в PS2 не имеют.

## Языки

Европейская DS-версия выбирает язык по системному (En, Fr, De, Es, It). Учесть в этапе 9 (пакеты перевода).
