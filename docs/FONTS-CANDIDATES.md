# Шрифты для чёткого текста реплик (9в.10.5)

Нужен шрифт без засечек (или с мягкими формами, как у интерфейса игры), с кириллицей, латиницей и знаками препинания, которые есть в переводе (`…`, `—`, `«»`, `ё`). Лицензия должна позволять класть шрифт в дистрибутив; сейчас он нужен приложению, а не ROM, и в репозиторий попадать может.

Лицензии ниже записаны по памяти авторов и перед включением в сборку проверяются по файлу `OFL.txt`/`LICENSE` каждого шрифта (КТ: файл лицензии лежит рядом со шрифтом, запись в `docs/THIRD-PARTY.md`).

| Шрифт | Лицензия | Характер | Заметки |
|---|---|---|---|
| **Ubuntu** (взят пока) | Ubuntu Font Licence 1.0 | гуманистический, чуть угловатый | уже в `epaint_default_fonts` (Ubuntu Light), кириллица есть; лицензия свободная, но не OFL (условия на переименование изменённых копий) |
| **Nunito** | OFL 1.1 | округлый, дружелюбный | ближе всего к мягкому виду интерфейса игры; кириллица есть; семейство с весами |
| **Rubik** | OFL 1.1 | скруглённые углы, плотный | хорошо читается мелким кеглем на светлом и тёмном фоне |
| **PT Sans** | OFL 1.1 | нейтральный, делался для русского | эталон по кириллице, мелкий текст читается ровно |
| **Fira Sans** | OFL 1.1 | гуманистический, чёткий | широкий набор знаков, много весов |
| **Noto Sans** | OFL 1.1 | нейтральный, покрывает почти всё | запасной вариант на случай редких знаков и других языков |
| **Source Sans 3** | OFL 1.1 | сдержанный | хорош для длинных реплик |
| **Comfortaa** | OFL 1.1 | геометрический, закруглённый | выразительный; на длинном тексте утомляет, годится для заголовков |
| **Marmelad** | OFL 1.1 | рукописно-мягкий | ближе всего к «игровому» духу, но читаемость ниже |

## Как выбирать

1. Снимок одной и той же реплики («Ты опоздал, искатель.», самая длинная реплика сцены) в 3–4 шрифтах, окно 1280×720 и 1920×1080, без сглаживания 2D.
2. Смотреть: читаемость мелким кеглем, `ё`, `…`, длинные слова, вид рядом с портретом.
3. Для кандидатов нужен вес: одиночный `Regular` (+`Bold` для выделений, если игра их различает; пока не различает).

## Решение

Пока Ubuntu Light. Список пересматривается после 9в.10.5, когда текст выводится в окне и можно снять кадры.
