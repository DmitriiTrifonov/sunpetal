# goto без меню запросов (K-234)

Цель: попадать в главу из идущей игры (окно, `--script`, REPL), не гоняя слепую последовательность нажатий от титула (`Session::go_to_request_list`).

Статус: **начало главы (`Cnn_01`) — работает**, `sunpetal_runtime::console::start_chapter(n)`, команда `chapter N` (консоль окна, REPL), `goto Cnn_01` в окне. Сцены `Cnn_yy` дальше начала — пока прежним путём (рестарт с `--goto`).

## Механизм

- Меню запросов (оверлей 3, `0x020A1680`) по подтверждению зовёт `0x0204E72C(N)` (глава в `0x02078638`, флаг `0x02078658` = 1) и `0x0201C5B0(mode, param)` (запрос смены режима).
- Контроллер режимов `0x0201C544` работает каждый кадр. Блок `G = 0x02069B64`: `[G]` — указатель на задачу текущего режима, `[G+4]` — запрошенный режим (0 — нет), `[G+8]` — параметр. Таблица режимов `0x02061E14` (8 байт на строку); строка 2 — мир (оверлей 4, колбэки `0x020A1E00`).
- `0x0202CA00(задача)` даёт 1, когда `[задача+0x14] == 0 && [задача+0x18] == 0` (задача закончена); тогда контроллер обнуляет `[G]` и создаёт задачу запрошенного режима.
- Вход мира `0x020A0520` зовёт `0x02022630(флаг, глава, память)`; `0x02024610(N)` строит `Chapter/Pack/C%02d/C%02d.evn`; цикл событий `0x02023744` стартует `Cnn_01` по имени.
- Прежние «читатели» флага (`0x0203E2D4`, `0x020310E8`) — операции с кучей, ложные срабатывания. Голый poke главы и флага ничего не делает.

## Вызов

`start_chapter(n)`: poke `0x02078638 = n`, `0x02078658 = 1`, `[[G]+0x14] = [[G]+0x18] = 0` (текущая задача «закончена»), `[G+4] = 2` (мир). Нужны глава 1..19 и идущий режим (`[G] != 0`). Через несколько кадров сцена — `Cnn_01`.

## Проверки

- Равенство: `goto C05_01` + 6×`advance 3000` и `goto C02_01` + `chapter 5` + `run 100` + те же `advance` — одинаковые реплики (6 строк), сцена `C05_01`, `value 0` = 0.
- Консоль окна, `--script`: `console goto C05_01 / C03_01 / C11_01 / C08_01 / C14_01` подряд — сцена каждый раз та (кадр `artifacts/console/c3.png`).

## Не проверено

Чистота (звук, GPU, память) при многократных переходах; старт из титула/меню (там `[G]` — меню запросов, должно работать так же); главы 1, 9–19 по реплике. `Cnn_yy` дальше начала: `goto_event` (setvalue, двери, телепорт) от нового начала главы.
