# Номер карты → область (K-230, разведка)

Код: функция `0x02026110` (Thumb, ARM9) — загрузка области по номеру карты `r6` (аргумент `r1`). Она собирает пути форматами `Model/Area/A%02d/a%02d_%02d%s`, `.../a%02d%s`, `.../SE%02d%s` (строки в ROM `0x664A8…`), и подставляет в них **сам номер карты**.

**Правило: карта N = каталог `Model/Area/A{N:02d}/`.** Единственная строка исключений (таблица `0x020624A4`, 3 байта на запись, одна запись): карта **60** при ответе функции `0x02024A0C` = 15 берёт область **15**; иначе обычная A60 (там `A60_Pass.cam`). Других подстановок нет.

Отсюда: «номер карты скрипта ≠ номер области» (NEXT A5) не подтвердился кодом. Карта 89 в прологе — каталог `A89` (по таблице `data/ult/areas.toml` это лифтовый холл/ входная зона, а шлагбаум — другая карта; сверять сценой, не числом).

Каталоги областей в ROM (по `data/ult/areas.toml`, 85 файлов): A00–A16, A18–A30, A33–A42, A44–A47, A50–A75, A77–A91.

## Что не сделано (в КТ: `sunpetal-debug --map N`)

`changemap MAP X Y Z` в REPL работает только внутри идущего скрипта (`docs/debug-tools.md`); на `C02_01` сразу после `--goto` и после `skip` карта не сменилась (кадр после `changemap 45` и 400 кадров — прежняя комната, `artifacts/ult/cam/m45.png`). Нужен путь: найти состояние, где обработчик действует (скрипт на паузе в `WAIT`, а не диалог), либо вызывать загрузку области `0x02026110` напрямую. Это шаг дальше, карточка K-230 остаётся в работе.
