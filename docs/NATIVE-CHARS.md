# Нативные команды персонажей: пилот толстого обработчика (K-190, Э1.3)

Флаг `SUNPETAL_NATIVE_CHARS=1` (все) или список `finder,pos,dir,motion` (для поиска расхождения). Код: `crates/sunpetal-runtime/src/nativechar.rs`. Умолчание не меняется.

## Что заменено

| Функция ARM | Что делает | Нативно |
|---|---|---|
| `0x020245B0` поиск персонажа (49 строк C) | id → запись в таблице (16 записей по `0x1E80` от `[0x0206B460]+4`, id в `+0x5C`); id 0 → `[base]`, id −1 → `0x02076308`; **пишет бит «встречен» в сохраняемые маски `0x0209C9CC…`** (через `0x02024B6C`) | да |
| `SETCHARPOS` `0x0204863C` (20) | позиция `+0x18/+0x1C/+0x20` из параметров | да |
| `SETDIRECTION` `0x0204975C` (24) | градусы → 16-битный угол в `+0x4C` (`direction()`) | да |
| `SETMOTION` `0x0204875C` (31) | поиск + вызов `0x02028BC0`/`0x02028BF8` (движение, ≥100 — другая ветка) | обвязка нативно, движение — функции игры |
| `WALKTO`, `SETACTION`, `CHARFOCUS*`, `SETFACE2`… | вызывают математику (`0x020192EC` деление, `0x0201929C` умножение 64 бита), `0x02028Bxx`, `0x02003014`… | не сделано |

## Результат КТ

Паритет: `tools/script/chars_blind.sh ROM SAVE OUT 6000` — 19 сцен × 6000 кадров, ARM против нативного: хэш обоих экранов и **хэш 16 записей персонажей + масок «встречен»** (`session::character_hash`, последний столбец `dialogref`) равны по каждому кадру, расхождений 0. Покрытие ограничено: за 6000 кадров от начала сцены команд персонажей мало (поиск зовётся ~сотнями раз на кадр-окно из оверлея, сами `SETCHARPOS/DIRECTION/MOTION` — единицы); сцены с ходьбой/`WALKTO` в наборе не проверены.

## Цена и находки

1. **Время игры считается безопасными точками** (`ARM_POLL`: вызовы, обратные переходы; `docs/ABI.md`). Нативная функция их не тратит → кадр перехода сцены отличался (1 кадр из 3000, при равном состоянии). Лечится `spend(n)`: списать столько же точек, сколько прошёл оригинал (поиск: 1 + 1 для id 1..128 + шаги цикла). **Каждая подмена обязана считать точки оригинала** — иначе тайминг «уплывёт»; для больших функций с циклами по данным это число надо выводить по пути, а не константой. Раньше пилоты (диалог) этого не требовали, потому что их замены не меняли путь по времени.
2. **Скрытый побочный эффект:** «поиск» пишет в сохраняемые флаги (кто встречен). Без хэша масок он был бы незаметен; сохранение изменилось бы молча.
3. Работа: 0,3 ч по часам замера (без пауз), 186 строк Rust с 2 тестами на 4 функции (≈125 строк C). Математика (деление, 64-бит) — вызовы библиотеки, переносятся механически (`direction()` проверена паритетом; неточность угла 16381 вместо 16384 для 90° — как у игры).
4. Дальше (`WALKTO` и др.): нужны `0x02028BC0/BF8` (движение) и `0x02003014/02002C3C` — это уже слой анимации/физики; цена за функцию растёт с глубиной, а не с числом команд.
