# Нативное рисование окна диалога (K-189, Э1.2, вариант Б)

Цель: измерить цену варианта Б — рендер текста окна диалога в хосте, а не в ARM-коде. Текст рисует библиотека
Nintendo `NNS_G2d` (холст символов, CharCanvas) в тайловую карту окна (VRAM `0x06001C8E…`, тайлы `0x06001800…`,
палитра 13, 144 тайла).

## Цепочка (ARM9, ARM-состояние)

| Адрес | Что делает |
|---|---|
| `0x020338E0` | блит буквы в холст: `r0` холст, `r1` объект шрифта, `r2`/`r3` x/y, стек: индекс цвета, дескриптор глифа; клиппинг по холсту |
| `0x020336A0` | один тайл 8×8 буквы: ветки 4bpp (слово на строку) и 8bpp (два слова) |
| `0x02034C5C` | битридер битмапа глифа (старшие биты первыми) |
| `0x02033194`, `0x02033280`, `0x020332C8` | поиск глифа и ширины (не портированы) |
| `0x02034398` | заполнение тайловой карты (не портировано) |

## Структуры (смещения библиотеки)

- Холст: `[0]` данные, `[4]`/`[8]` ширина/высота в тайлах, `[0xC]` бит на пиксель холста, `[0x10]` тайлов в строке.
- Шрифт: `[0]` → объект, `[8]` → ресурс: `[0]` ширина ячейки, `[1]` высота, `[6]` бит на пиксель глифа.
- Глиф: `[0]` → инфо (`[1]` ширина глифа), `[4]` битмап.
- Холст диалога `0x0229E594`, шрифт `0x02075AFC`.

## Объём (сцена C01_01, 3000 кадров)

609 блитов букв, 1765 тайловых блитов, 17 вызовов `0x02034398`.
Воспроизведение: `goto C01_01` + `callstrace 3000 OUT 020338E0,020336A0,02033280,020332C8,02033194,02034398`.

## Порт

`crates/sunpetal-runtime/src/nativedraw.rs`: `draw_glyph` над трейтом `Mem` (слово в слово с `0x020338E0`/`0x020336A0`/`0x02034C5C`),
`Recorded` для проверки «нативный результат против ARM». Подмена за `SUNPETAL_NATIVE_DIALOG_DRAW=1`.

## Журнал

- 189.1 разведка записана. 189.2: порт написан, 5 юнит-тестов (4bpp, край плитки, клиппинг, запись в сторону, битридер) зелёные;
  сверка с реальным ARM — следующий шаг (режим check: нативно в `Recorded`, затем оригинал, сравнение записей).
