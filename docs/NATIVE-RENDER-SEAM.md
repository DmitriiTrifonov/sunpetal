# Шов рендера: что игра подаёт 3D-движку (K-228, Э4.1)

Разведка на `C02_01` (комната 402, Катарина, 442 полигона за кадр). Код: `crates/sunpetal-runtime/src/scene.rs` (тип «кадр сцены»), REPL-команда `frame`.

## Уровни шва

| Уровень | Где | Что видно | Годится для |
|---|---|---|---|
| Команды GX (`MTX_*`, `VTX_*`, `BEGIN_VTXS`) | `gx.rs`, поток из DMA/FIFO | всё, но без имён: матрица позиции = вид × модель, вершины в единицах модели | подмена сейчас сделана здесь (`ult_*`), заплаткой по адресу display list |
| Списки `Lists` (`verts`, `polys`, `srcs`) | `gx.rs`, `Gx::build/render` | `srcs`: адрес-источник BEGIN_VTXS, число полигонов, слот матричного стека (кость), матрица позиции первого батча | «кто есть кто» (`modelsrc.rs`: файл, модель, меш) |
| `Job` | `render3d.rs` | уже после отсечения и проекции: экранные вершины, `GxPoly` | рендереры (софт, GPU); для свободной камеры поздно |
| **Кадр сцены** (новое) | `scene.rs` | камера (вид `0x02071108`, проекция `0x020710C4`) + предметы: модель/меш, кость, число полигонов, матрица позиции | свободная камера, подмена целой модели без заплатки на GX, моды |

## Замер на `C02_01`

- 442 полигона за кадр, 231 запись (батч-источник + кость); **421 полигон (95 %) названы** моделью и мешем: `no46_room_402r` (комната, 241), `ch_01_sumio_anim` (героиня, кости слотов 2–14, 127), `shadow` (44), `item_01_katharin` (9). 21 полигон без имени — батчи не по DMA (опознаются по словам, `ult_pend`).
- Вид и проекция читаются из RAM как есть; проекция `[20863, 28376, −16396, −16384, −9828]` (1.19.12, перспектива 4:3).
- Матрица позиции предмета — уже вид × модель: мировая = вид⁻¹ × позиция. Камеру можно менять над кадром, не трогая предметы (`nativecam.rs` правит вид).

## Тип кадра

`SceneFrame { view, proj, items: Vec<SceneItem{ model, mesh, slot, polys, pos }> }`; `capture()` читает работающую машину, `hash()` — FNV-1a по всему кадру. Проверено: два запроса подряд дают один хэш, после `advance 1` другой (анимация).

## Не сделано (КТ «хэши кадров равны потоку GX»)

Хэш считается по структуре кадра, не по потоку GX. Равенство потоку появится с обратным путём «кадр сцены → задания рендера» (Э4.2). Сейчас кадр только читается; подмена по-прежнему в `gx.rs`. Вершины и текстуры в `SceneItem` не входят: их даёт файл модели по `model/mesh`, анимацию — слоты костей и матрицы.

## Выводы

1. Шов «кадр сцены» есть и дёшев: на 95 % полигонов хватает `modelsrc.rs`.
2. Чтобы PS2-модели ставились без заплатки на GX, рендерер должен получать `SceneFrame` + файлы моделей (Э4.2); первый шаг — перенести туда замену модели (`Ult`) и матрицу позиции.
3. Свободная камера: правка вида после `MTX_LookAt` (K-233) работает на этом шве; отсечение по камере игры остаётся (читатели `0x0201FF58`, `0x02027DF8`, `0x0202A686`).
