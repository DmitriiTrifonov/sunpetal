## Что знать, чтобы не наступить

- В этом дереве могут работать две сессии сразу (сильная модель и модель дешевле). Перед правкой общих документов смотреть `git status` и `git diff`, коммитить только свои файлы, чужие незакоммиченные не трогать.
- C13_01 идёт на крыше отеля (`no28_ht_roof`), не у кинотеатра `no67_palavision`; какие модели DS в кадре, говорит команда `batches` в `--repl`.
- Картинка материала в выгрузке `sunpetal-ee` может быть меньше страницы `TEX0` (до X-32): uv всегда по странице `1<<tw × 1<<th`.
- Улица PS2 — общий мир в одних координатах (сдвиг 0), карты DS перемоделированы: вершины рядом, но не совпадают; мерить `loose`, не точную долю. Самая частая разность вершин как сдвиг ненадёжна (плотные скопления) — `same_model` перебирает кандидатов.
- Сцены DS сделаны из сцен PS2: сначала пробовать «та же модель со сдвигом», совмещение по габаритам/картинкам — только запасной путь (оно уже раз дало ложный ответ со score 0,835).
- Вершины подмены идут через clip-матрицу якорной пачки, в ней уже матрица узла и POSSCALE: place — в единицах display list якорного меша. Якорь называть явно (`--anchor`): узлы модели DS имеют разные сдвиги.
- Кадр `--goto C02_01` (120 кадров после входа) — это катсцена с «on air», не свободная ходьба; кадр «до» снимать той же командой без `SUNPETAL_ULT_MODELS`.
- Подмена: стены и пол комнаты идут не через DMA, а копированием через процессор; такие пачки опознаются по первым словам списка (`modelsrc::model_by_words`).
- `vtx.bin` выгрузки — 40 байт на вершину (`<6f4B2f4B>`); позиции × `scene_scale` (0,1) = единицы сцены, они же единицы модели DS.
- Номера текстур из отчёта K-001 (`АРХИВ.BIN#запись.N`) к слотам `textures.tsv` выгрузки отношения не имеют; соответствие — по содержимому через `tools/ult/match_k001_ids.py`.
- В Python проекта нет `PIL` и `numpy`: PNG читать/писать через `tools/ps2/lf.py` (`read_png`, `write_png`).
- Хук перед коммитом (`tools/verify.sh quick`) срабатывает и на обычные команды Bash и отклоняет их, если дерево не проходит `cargo fmt --check`/`clippy -D warnings`: временную отладочную печать в Rust писать сразу отформатированной и убирать инструментом Edit.
- В zsh переменная со списком аргументов не разбивается на слова: для аргументов брать массив `P=(--a 1 --b 2)`.
- Сцены `--goto Cnn_01` глав 1, 5, 7 начинаются в одной комнате 402: для другой карты нужен маршрут (`walk`, `changemap`) или закладка автора.
- Движения DS и PS2 по длине в кадрах не сопоставляются (скелет DS — 21 кость); запасной путь «PS2-части на костях DS» вероятнее основного.
- Агент `sunpetal-ee` работает своим циклом по `notes/queue.md`; наши задачи ему — `X-NN` и `Y-NN`. В его дерево не писать, кроме очереди и по слову автора.
- Модели: ворота и рендер под паритет — сильной моделью; рутину с ясной проверкой — моделью дешевле или DeepSeek через OpenCode (скилл `orchestration`).
