# Модели PS2: охват сцен и таблица «DS → PS2» (K-112, 2026-11-10)

Часть 1 из 2 карточки K-112: охват и таблица. Часть «кости и анимации» ждёт K-155/K-157 (читатель DS MDL0/NSBCA) и K-199 (узлы персонажей), здесь не сделана.

## Что сделано

- Каталог моделей раньше покрывал 11 архивов (125 моделей, из `R*` только `R00`). Извлечены остальные 18 архивов `DATA/EVENT/R01…R19.BIN` из английского образа (`build/ps2-models/raw-r/`, не в git) и прогнан `catalog.py` + `check_models.py` в `build/ps2-catalog-r/`: **+472 модели, всего 597**. Красных в новой части 174, спорных 29, зелёных 269.
- `tools/ps2/model_coverage.py` (тесты `test_model_coverage.py`, без данных игры) соединяет модели PS2 с ключами текстур DS по парам K-001 (`k001-report.csv`: ключ DS → `АРХИВ.BIN#запись.текстура`) и статусом K-183. Выход: `build/k112/models.csv` (таблица по моделям), `build/k112/ds_only.csv` (ключи DS без пары).

```
python3 tools/ps2/model_coverage.py --pairs build/k001/k001-report.csv \
  --catalog build/ps2-catalog/index_metrics.csv --catalog build/ps2-catalog-r/index_metrics.csv \
  --out-models build/k112/models.csv --out-ds build/k112/ds_only.csv --summary
```

## Результат

| Решение | Моделей | Смысл |
|---|---|---|
| `swap` | 63 (28 статичных, 35 составных) | зелёная модель + есть пара ключей DS → подмена по ключу (механизм K-111/K-128) |
| `blocked` | 16 | пара есть, но модель красная/спорная (части не расставлены: `OP#13–14, 21`, `R00#20, 32, 34, 44`, по одной в `R01, R04–R06, R08, R09, R11, R12`) → ждёт K-199 |
| `unpaired` | 518 | меш есть, пар текстур нет |

Ключи DS: 1626, пара PS2 у 816 (50 %), **810 без пары — остаются DS** (вход для K-113: апскейл/перерисовка). 12 ключей парны записям PS2 без меша (текстуры спрайтов/интерфейса).

Пары почти все в `R00` (504) и `OP` (193): остальные 18 архивов дают 119. Поэтому `swap` сосредоточен в `R00` (28) и `OP` (13); в `R01, R03, R04, R06, R08–R10, R16` подменять пока нечего. Самые «жирные» по числу пар: `OP#10` (86), `R00#1` (83), `R00#38` (48), `R00#2` (41), `R00#21` (35).

## Что это значит

1. Охват сцен через модели PS2 по текущим парам — около 63 моделей, в основном парковка (`R00`) и вступление (`OP`). Остальные главы подменой по ключу не закрыть: пар текстур нет (K-001 сняла 18 глав DS, но пары нашлись в основном для `R00`/`OP`).
2. 518 `unpaired`-мешей (185 зелёных статичных) — кандидаты на сопоставление **по геометрии**, а не по текстуре: нужна трасса GX сцены (габарит пачки) против bbox меша. Это следующий шаг, для него нужны кадры DS по главам.
3. Соответствие «архив R01…R19 → глава/сцена DS» не установлено, таблица по сценам DS невозможна без него; по `R00` известно, что это парковка (PS2-RECON).
