# Разведка PS2-образа (2026-10-24)

Нужна для этапа 7 (пакеты текстур): откуда брать картинки для замены текстур DS-версии. Образы: `~/Developer/games/fsar-ru/roms/Hana to Taiyou to Ame to (Japan).iso` и `(English v1.0).iso` (оба 3 759 833 088 байт). Только чтение, в репозиторий ничего из образа не попадает.

Инструмент: `tools/ps2/iso.py` (минимальный читатель ISO 9660: `ls`, `tree`, `cat`).

## Состав диска

- `SLPS_250.34` (ELF PS2, 4,8 МБ), `SYSTEM.CNF`, модули IOP (`*.IRX`, `IOPRP214.IMG`).
- `DATA/`: `SYSTEM/SYSTEM.BIN` (0,3 МБ), `NAKA/NAKA.BIN` (15 МБ), `NAKA/MOVIE/MOVIE.BIN` (612 МБ, видео), `WAT/WAT.BIN`, `YOSHI/YOSHI.BIN`, `KAWA/KAWDAT.BIN`, `TORU/*.BIN` (по 14–18 МБ) и `TORU/EFFECT/EFFECT.BIN`, `EVENT/R00..R19.BIN` (комнаты и события, 20–65 МБ каждая), `EVENT/OP.BIN`, `EVENT/GDB.BIN`, `PCM0..2.BIN` (звук, 0,5–1,2 ГБ), `VBST.BIN`.
- Каталоги внутри `DATA` (`KAWA`, `NAKA`...) с именами авторов-программистов, то есть каждый кусок игры собран своим человеком, форматы могут отличаться.

## Контейнеры

- Стандартных текстурных сигнатур нет: `TIM2` и PNG в `SYSTEM`, `NAKA`, `WAT`, `YOSHI`, `R05`, `OP`, `KAWDAT`, `TORUDAT` не встречаются.
- Архивы `.BIN` начинаются с `4C 46` (`LF`), затем байт-номер (`05`, `30`, `39`, `06`, `49`, `2F`, `04`, `14`: разный в каждом файле) и `00 01 00 00 00`, потом 32-битные слова (смещения или размеры). Формат не разобран.

## Что дальше

1. Разобрать заголовок `LF`-контейнера (по `SYSTEM.BIN`, он самый маленький: 315 392 байта): таблица смещений, сжатие (искать LZ-сигнатуры, сравнивать энтропию), вложенные файлы.
2. Найти среди вложенных данных картинки PS2: они чаще всего лежат как кадры GS (PSMCT32/PSMT8/PSMT4 с палитрой CLUT) или как «TM2»-подобные куски без заголовка; признаки: размеры степени двойки, палитра на 256 цветов (1 КБ), выровненные по 16 байт блоки. Помогает разбор загрузчика в `SLPS_250.34` (строки с именами файлов, вызовы чтения).
3. Выгрузить картинки в PNG, сопоставить с выгрузкой текстур DS (`--dump-textures`): сначала глазами и по размеру на 5–10 текстурах, потом по похожести (уменьшенная копия, цветовая гистограмма, фаззи-хеш). DS-версия 2008 года не копия PS2-версии 2001 года: модели, развёртки и ракурсы могут отличаться, прямого соответствия может не быть. Решение об автоматизации принимать после этой проверки.
4. Для сопоставленных текстур собрать пакет (имена по ключам, `docs/ABI.md`, раздел про пакеты) с масштабированием под размер замены.
