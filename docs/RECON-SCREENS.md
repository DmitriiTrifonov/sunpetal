# Разведка по экранам (этап 8б), 2026-10-27

Что игра показывает на верхнем и нижнем экранах и что нужно от игрока. Снято на европейском ROM через `sunpetal-debug` (`--goto`, `--repl`, команды `press`, `tap`, `shot`) на 100%-м сохранении. Снимки лежат в `build/recon8b/` и в репозиторий не входят (это картинки игры).

## Таблица

| Режим | Верхний экран | Нижний экран | Касание нужно | Один экран |
|---|---|---|---|---|
| Титул, меню «SAVE DATA» (Continue, Next Days, Request, Option, Back), список запросов R-00… | портрет хозяина и поясняющая фраза, не интерактивны | **все кнопки меню**, ключи, список запросов | да, всё управление | нижний |
| Поездка (R-00) | 3D-сцена: дорога, машина | карта острова и счётчик, только показывает | нет | верхний |
| Диалог (C02, C04…) | 3D-сцена, окно реплики, портрет | та же карта и счётчик, без действий | нет (A листает) | верхний |
| Свободная ходьба | 3D-сцена, герой, значок предмета для осмотра | карта; по START в правом нижнем углу появляется кнопка меню, по касанию слева открывается полоса значков (чемодан, предметы) | да, только для меню | верхний; нижний по запросу |

| Меню чемодана: GUIDE BOOK, MEMO, SAVE, GOODS | циферблат устройства остаётся | четыре пункта в строке (y≈90), стрелка возврата справа внизу | да | нижний |
| Guide Book | «GUIDEBOOK 1/49», обложка или страница | сетка номеров страниц 4–49 по разделам, стрелка листания | да (номера, листание) | верхний — страница, нижний — выбор номера: оба по очереди |
| MEMO | заголовок и клетчатое поле, рисунок идёт через границу | клетчатое поле | да, рисование по обоим | оба (исключение), видно пол-листа на экране |
| SAVE (из чемодана) | Эдо, «Save data?» | пуст на снимке; выбор нужно снять отдельно | да (выбор Yes/No, не снято) | верхний — подсказка, нижний — выбор |
| GOODS | портрет и описание выбранного | список профилей 01–11, стрелка прокрутки | да (список) | верхний — портрет, нижний — список: оба по очереди |
| Значок с числом на карте (слева, под чемоданом) | сцена | счётчик шагов («018»), не кнопка | нет | верхний |
| Титул, Request | Эдо с подсказкой «Play from the start of the selected request number» | кнопки R-00, R-01, R-02, Next, Back (после касания Request; через ≈ 60 кадров гаснут) | да, три кнопки | нижний (подсказка сверху вторична) |
| Стартовые логотипы | Rising Star Games всё время | Grasshopper (≈ кадр 200), h.a.n.d. (≈ 400) | нет | **оба по смене картинки** (B-09: сейчас нижние логотипы не видны) |
| Заставка «花», вставка «FSR», ролики | картинка ролика | чёрный | нет | верхний |

## Что не исследовано

- Осмотр предмета, выбор ответа в реплике, головоломки (в приложении уже есть `dial_scene`), Lost List, карта поездки, ролик после R-00 и остальные ролики (`PLAYMOVIE`), кнопки Yes/No экрана SAVE, список R-00…R-02 на разных стадиях, Guide Book постранично (снята только сетка). Снять тем же способом, это следующий шаг.
- Какие метки даёт игра: уже известны указатель на команду скрипта и слово `0206577C` (`docs/F7-SKIP-STATUS.md`). Нужны метки для «сейчас меню» и «сейчас головоломка».

## Выводы для режима одного экрана

1. Нижний экран в сценах (диалог, ходьба, поездка) показывает только карту. Её можно спрятать или дать маленьким оверлеем (раздел о переносе элементов в плане 8б).
2. Нижний экран — единственный «управляемый» в меню, списках, чемодане: там нужен нижний экран целиком.
3. Правило автопереключения: **верхний, пока идёт сцена (скрипт шагает, окно реплики, ходьба, поездка); нижний, пока открыто меню, список, чемодан или головоломка**. Опираться на метки скрипта (как в F7-пропуске) и на то, что в меню скрипт не шагает; граничные случаи уточнить по неисследованному списку.
4. В свободной ходьбе нужен доступ к кнопке меню (правый нижний угол нижнего экрана): оверлей-кнопка в режиме одного экрана, при нажатии переключение на нижний.

## PS2-версия как образец (снимки PCSX2, 2026-10-27)

Источник: 16 снимков `~/Library/Application Support/PCSX2/snaps/` (22–23 октября, вступление R-00 и экран устройства; часть с русским текстом проекта перевода; копии в `build/recon8b/ps2/`, в репозиторий не входят). Сохранения состояния PCSX2 (`sstates`) без эмулятора не открыть. Снимков меньше, чем режимов: диалог в машине, диалог на трассе, титул, панель Катарины.

- **Одноэкранный режим PS2 = верхний экран DS, растянутый на 4:3.** Те же элементы: полоса «on air» сверху, красные линии, 3D-сцена, окно реплики внизу с портретом. На PS2 портрет **справа**, на DS слева; текст идёт слева от портрета.
- **Карты и счётчика нижнего экрана в диалоге нет.** Значит, в сценах нижний экран не нужен, подтверждение вывода 1 из таблицы выше.
- **Устройство (панель Катарины)** на PS2 — оверлей в правом нижнем углу поверх сцены: циферблат с цифрами, ручка «Juck», подпись «Katharine control panel» и схема с подписями «Dial» и «Juck» вверху справа. То есть то, что на DS занимает нижний экран, на PS2 — выезжающая панель в углу (с наклонной линией разделения). Это образец для оверлея «нижний экран поверх верхнего».
- Для меню, списка запросов, справочника, головоломок снимков нет. Их раскладки на PS2 можно получить только из `WAT.BIN` (полноцветные 2D-экраны 512×256 и 320×240, `docs/PS2-RECON.md`) или из новых снимков PCSX2.

### Что из этого следует

1. Режим одного экрана по умолчанию = верхний экран; PS2 это подтверждает как задумку оригинала.
2. Устройство и меню показывать оверлеем-панелью в углу (как на PS2), а не переключением экрана целиком; переключение на нижний оставить для меню, списков и головоломок, где нужна вся поверхность.
3. Чтобы взять оттуда больше (справочник, головоломки, меню), нужны снимки PCSX2 этих режимов: кто-то (вы) делает их в эмуляторе, либо я извлекаю экраны из `WAT.BIN`.

### Дополнение: снимки и записи PCSX2 от 27 октября

Свободная ходьба, устройство, запись экрана (кадры из `~/Desktop/Запись экрана…`, снимки `snaps/…152626–152657`; копии в `build/recon8b/`, не в репозитории).

- **Ходьба на PS2 — чистая 3D-картинка без интерфейса**: ни карты, ни счётчика, ни кнопок. Объект, с которым можно взаимодействовать, помечен кругом на цели (зелёный круг, красные и зелёные кольца вокруг). Значит, счётчик карты на верхнем экране DS — не PS2-образец, а наш добавок; в настройках он уже отключаем (`[video] counter`).
- **Устройство Катарины на PS2 — режим всей сцены**: тёмный фон, фиолетовая линия-осциллограмма во всю ширину, чемодан с циферблатом **внизу справа** (цифра выбранного значения в окошке циферблата, подпись «SELECT 0123456789»), вверху справа схема «KATHARINE CONTROL PANEL» с подписями «Dial» и «Juck». Режим поиска: красные рамки на области, красные частицы по всему экрану, цифры красными квадратами, при попадании зелёные цифры «HIT». Управление кнопками, не касанием. То есть на PS2 устройство — угловой элемент во весь режим, и наш оверлей-панель в правом нижнем углу для него подходит по положению.
- **Окно выбора в диалоге**: подсказка «Press the Circle button to confirm and the X button to cancel» в окне реплики (кнопочная замена касания).
- Диалог: окно реплики снизу, портрет справа (на DS слева), красный блок слева у окна появляется анимацией перед текстом.

### Что это меняет

1. Кнопка меню для ходьбы: на PS2 меню открывается кнопкой, экранной кнопки нет. На одном экране DS нужна наша кнопка (панель касаний на телефоне, угол без неё).
2. Устройство и головоломки с циферблатом: показывать верхний экран с нижним панелью в правом нижнем углу (`overlay`), как на PS2; полный нижний экран остаётся для меню.
3. Не снято: Guide Book, меню из ходьбы (после «START»), чемодан с пунктами GUIDE BOOK/MEMO/SAVE/GOODS, список запросов.

### Дополнение: сохранение и экран Эда на PS2 (снимки 27 октября, 15:45)

- **Сохранения в игре нет, только у стойки Эда между главами.** Экран «WELCOME?» (Эд Макалистер): портрет слева внизу, справа текст «Do not forget to save before going on to the next chapter! End the game without saving and all your progress will be lost!»; затем меню из трёх ключей «Next Days R-01», «Save», «Game End». Значит, в PS2 нет и пункта SAVE в чемодане: это нововведение DS (там Катарина открывается когда угодно).
- **Экран Эда на PS2 целиком на одном экране**: портрет слева, текст или ключи справа, чёрный фон. На DS то же разложено на два (портрет и текст сверху, кнопки снизу). Образец для режима одного экрана: собирать такой экран из двух (портрет и текст с верхнего, ключи с нижнего), раздел «Меню в стиле игры» (8г).
- Экран карты памяти «Hello!! MEMORY CARD (PS2)» («Format complete. Press × to continue.»): только PS2.
- Главное меню PS2: Play Start, Request, Movie, Option (на DS Continue, Next Days, Request, Option); «Movie» — просмотр роликов.

### Дополнение: устройство на PS2 со справочником (снимок 15:56)

Схема «KATHARINE» вверху справа показывает три органа: «Dial» (циферблат), «Juck» (кнопки подключения, слева) и **«Guide Book»** (зелёная рамка внизу, книжка «The Lospass»). Значит, и на PS2 справочник живёт в чемодане Катарины, рядом с циферблатом и подключением; та же панель выезжает в правом нижнем углу, герой стоит в тёмной сцене с осциллограммой слева. Сохранения и MEMO в схеме нет (у DS есть SAVE, MEMO, GOODS).

### Дополнение: как оформлен справочник на PS2 (снимки 15:56–15:58)

- **Открытие.** Чемодан открывается, внутри лежит книжка «The Lospass»; сцена уходит в тёмный фон с осциллограммой, справа сверху схема устройства (Dial, Juck, Guide Book; органы подсвечены цветом активного режима).
- **Страница крупно слева, панель справа.** Левые ~55% экрана занимает страница; правую треть отделяют две диагональные линии: заголовок «KATHARINE», два окошка с номерами страниц (разворот, например `05` и `04`), миниатюра разворота книги, «Page Select» с зелёными стрелками влево и вправо, внизу справа наклонный превью текущей страницы.
- **Обложка и картинки — страницей целиком** (картинка слева), **текстовые страницы — живым текстом** (заголовок крупнее, абзацы светло-серым по тёмному, без картинки подложки); ниже и выше текста колонка жёлтых стрелок прокрутки (вверх/вниз), когда текст длиннее экрана. Страницы с картой острова показывают карту превью справа.
- На DS справочник — набор растровых страниц (48 файлов `Guide`, `docs/TRANSLATION-RECON.md`), без живого текста: переводчики перерисовывали их картинками.

**Для режима одного экрана:** на DS страница на одном экране со своими стрелками «Page Select» (касанием), номерами и миниатюрой разворота; PS2 даёт образец раскладки (страница слева, панель с номерами и стрелками справа), но не механику: стрелки у нас работают касанием нижнего экрана, и панель надо собрать из частей двух экранов тем же способом заплаток.
