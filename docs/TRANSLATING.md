# Как сделать свой язык

Перевод игры — это таблица текстов и, по желанию, перерисованные шрифты и картинки. Ничего из игры в перевод не входит: в языковой пакет попадают только ваши тексты и бинарные дельты к файлам вашего ROM. Нужен ваш собственный дамп европейской версии (код игры `YHNP`).

Все программы собираются так: `cargo build --release -p sunpetal-data`, они лежат в `target/release/`.

## 1. Заготовка таблицы

```sh
sunpetal-translate export --rom GAME.nds --lang Polski --out polski.csv
```

Получится CSV (UTF-8) со столбцами `Chapter, Scene, ID, Original, Polski`. В `Original` английский текст европейского ROM (папка `ue`), последний столбец пустой: туда переводится. Файл содержит текст игры, поэтому его не публикуют; в пакет попадёт только ваш столбец.

- Строки одной реплики разделены переводом строки внутри ячейки. В окне диалога помещается **3 строки**, ширина строки до **188 пикселей**.
- `ID` вида `01001#2` — повторный ID в одной сцене. `-` — файл целиком (интерфейс, подписи сохранений, профили).
- Управляющие коды вроде `{color,1}` оставляйте как есть.
- Пустая ячейка значит «не переведено»: в игре останется английский.

Если у вас уже есть таблица в другом формате столбцов, возьмите её в новую заготовку: `--from старая.csv --column "Название столбца"`.

## 2. Проверка

```sh
sunpetal-translate check --rom GAME.nds --table polski.csv --column Polski [--font font.nftr]
sunpetal-translate progress --rom GAME.nds --table polski.csv --column Polski
```

`check` находит: тексты, для которых в ROM нет места (опечатка в ID или сцене), повторы, реплики длиннее трёх строк, строки шире окна и символы, которых нет в шрифте. Код возврата 1, если нашлись проблемы. `progress` показывает, сколько переведено по главам.

Ширина считается по шрифту диалога. Родной шрифт игры знает только латиницу, поэтому для кириллицы, польских букв и других алфавитов нужен свой шрифт: передайте его в `--font`. Проверка ширины относится к диалогам; тексты интерфейса и подписи (`2D`, `EdoComment`, `Profile`) рисуются другими шрифтами и окнами, их надо смотреть в игре.

## 3. Шрифты и картинки

Пока это ручная работа: шрифт NFTR (`Chapter/Pack/Common/font.nftr` и три шрифта интерфейса в `2D`), перерисованные страницы справочника и подписи. Русский пакет сделан так: переведённые файлы лежат в собранном ROM проекта перевода, а `sunpetal-pack-translation --translated ПЕРЕВЕДЁННЫЙ.nds` сохраняет разницу с оригиналом как бинарные дельты (82 файла, ~750 КБ). Без `--translated` пакет содержит только тексты.

## 4. Упаковка

```sh
sunpetal-pack-translation --rom GAME.nds --table polski.csv --column Polski --lang pl --out polski.spdata
```

`polski.spdata` — языковой пакет: секции `TRAN` (тексты, дельты) и `META` (для какого ROM). Его можно раздавать: в нём ваш перевод и бинарные изменения к файлам ROM, текста оригинала нет. Чтобы добавить язык в уже собранный файл данных, `--merge sunpetal.data`. Если переведённые шрифты и картинки лежат в уже пересобранном ROM, дайте его в `--translated TRANSLATED.nds`: изменения возьмутся дельтами (так сделан русский пакет). Предупреждения вида `the table makes … differently` значат, что файл из таблицы и из переведённого ROM различаются: проверьте их.

## 5. Файл данных и проверка

```sh
sunpetal-build --rom GAME.nds [--disc GAME.iso] --translation polski.spdata [--translation ru.spdata] --out sunpetal.data
sunpetal-check sunpetal.data
```

`sunpetal-build` собирает один файл `sunpetal.data` из вашего ROM, по желанию PS2-образа (улучшенные текстуры, первый раз минуты, дальше из кэша) и любого числа пакетов перевода; пакет, сделанный для другого ROM, отвергается. `sunpetal-check` проверяет файл так же, как игра при запуске (версия, длины и контрольные суммы частей) и печатает, что внутри: части, языки, для какого ROM. Файл данных содержит данные игры из вашей копии и не распространяется; раздаётся только пакет перевода.

## 6. Играть

- **Десктоп:** запустите `sunpetal-app`. Если игры рядом нет, откроется окно выбора: `sunpetal.data` или `.nds`. Если в файле есть перевод на язык системы, он включится сам (один раз, при выборе); дальше язык меняется в меню («Язык игры») или флагом `--lang pl`. `--lang none` — родной английский текст.
- **Android:** положите `sunpetal.data` в папку приложения (`Android/data/org.sunpetal.app/files`) или выберите его при первом запуске. Файл данных с ROM внутри запускает игру без отдельного `.nds`. Язык игры по системному выбирается один раз при первом запуске, потом меняется в меню.
- **Без файла данных:** игра идёт от ROM, переводов и PS2-текстур нет.

## Что не готово

- Нет шрифтов для других алфавитов в готовом виде и инструмента их создания (нужен свой путь: TTF → NFTR; план 9в.4–9в.6 в `docs/PLAN.md`).
- Перевод интерфейса самого приложения (меню настроек) делается пока в коде (`crates/sunpetal-app/src/ui.rs`), сейчас есть английский и русский; вынос в файлы — 9в.2.
- Тексты, которые игра собирает кодом (имена, числа), в таблицу не попадают.
- Лицензию перевода выбирает его автор: пакет не покрыт лицензией кода (см. `NOTICE`).
