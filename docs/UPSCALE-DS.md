# K-113: улучшение DS-ресурсов без PS2-аналога

Эпик «Модели PS2» 5/5. Предмет: то, у чего нет парной картинки или модели на PS2 (текстуры: 806 из 1626 после K-001; модели: список из K-112). Способы по порядку: апскейл (`tools/ps2/upscale.py`, метод upscayl) → перерисовка. Правило проекта: ничего из игровых данных в git не кладём.

## Опись (2026-11-05, шаг 1)

Из 806 текстур без пары игра за 18 глав (выгрузка K-001) показала 57, из них не меньше 32×32 — 47. Лист: `artifacts/k113/sheet.png`, список `artifacts/k113/inventory.txt` (не в git). Типы:

| Группа | Номера на листе | Что |
|---|---|---|
| Лица | 1–6, 11–14 | атласы лиц 128×128; игра правит их в памяти, куски лиц в разных палитрах |
| Lost and Found | 28–32 | карточки предметов (пересекается с K-133) |
| Растения | 7, 8, 44, 46 | пальмы, кусты с прозрачностью |
| Стены, заборы, окна | 9, 16–27, 34–41, 43, 47 | бытовые текстуры 32–128 px |
| Интерфейс и эффекты | 10, 15, 33, 42 | «on air», кольцо, звезда F.S.R., блик |

## Пробный апскейл (2026-11-05, шаг 2)

12 текстур через `upscayl` ×4, лист `artifacts/k113/pairs_sheet.png`. Хорошо: пальма, окна, каменная стена, кусты, «on air», звезда F.S.R. Спорно: забор, бамбук (нейросеть выдумывает узор), горы (пятна). Плохо: блик 42 (мягкий градиент стал жёстким кругом: нужен `lanczos` без палитры), карточка Lost and Found 28 (текст превращается в кашу: перерисовка, K-133).
