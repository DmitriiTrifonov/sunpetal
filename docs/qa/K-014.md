# K-014. 109 строк русской таблицы шире окна или без глифов

**Цель.** Проверить, что ни одна из 109 русских строк не вылезает за плашку и не содержит пустых глифов.

**Предусловия.**
- Язык RU (`--lang ru`).
- Список строк: проект перевода (`~/Developer/games/fsar-ru`, только чтение), перечень 109 строк — уточнить у ассистента (файл с номерами).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Пройти по списку строк (через `--goto`/сохранение, где строка встречается). | Каждая строка целиком в плашке или обёрнута по ширине, без обрезания. |
| 2 | Проверить глифы: все буквы видны (ё, й, ъ, ы, знаки препинания, кавычки). | Нет «пустых квадратов» и отсутствующих букв. |
| 3 | Повторить в широком окне (21:9) и в узком (портрет). | Строки не вылезают за свои рамки ни в одной раскладке. |

**DoD.**
- Все 109 строк просмотрены: каждая «ок» или записана в список «не ок» с номером.
- Список «не ок» пуст для ПРОШЛО.

**Что приложить при неудаче.** номер строки, `window_N.png`, раскладка.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
tools/qa/play.sh ru --save build/user.sav   # к строкам идти через --goto Cnn_yy, см. docs/debug-tools.md
```
