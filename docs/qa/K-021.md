# K-021: тема меню, геймпад, звуки (проверка автора)

Сборка из дерева (`cargo build --release -p sunpetal-app`), запуск по `window-restart`, ROM указан (звуки берутся из него). Геймпад подключён.

1. **Вид.** START (на ходьбе) или F1: меню на весь экран, тёмно-синий фон, колонка посередине, текст крупный, углы прямые. Колесо и перетаскивание прокручивают список.
2. **Курсор.** D-pad вверх/вниз: оранжевые уголки идут по виджетам, список прокручивается за ними. Слайдер не держит фокус (вниз уходит дальше).
3. **Списки.** На любом выпадающем списке (раскладка, размер окна, шрифт) D-pad влево/вправо переключает значение без попапа; на слайдере двигает ползунок.
4. **Без мыши и клавиатуры.** «Экспорт в папку настроек» создаёт `sunpetal.sav` в папке настроек; «Импорт …» (файл `.sav`/`.dsv` оттуда же) просит подтвердить повторным нажатием. «Сохранить текущие» при пустом имени берёт «profile N».
5. **Звуки.** Открытие меню, переход фокуса, A (Enter): слышны короткие звуки игры. Если нет ROM-файла, звуков нет (так и должно быть). Громкость относительно игры: нормально / тихо / громко.
6. **Что не работает с геймпада** (известно): путь к 2D-картинкам, свой путь к текстурам, переназначение клавиш клавиатуры.

Результат: `K-021: ПРОШЛО | НЕ ПРОШЛО | НЕ ПРОВЕРЕНО`, номер шага.
