# K-028. Флаги сборки: opt 3, LTO, codegen-units 1

**Цель.** Проверить, что релизная сборка с новыми флагами работает так же и не медленнее.

**Предусловия.**
- Чистая копия: `cargo clean -p sunpetal-app` (по желанию).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | `cargo build --release -p sunpetal-app` на рабочем дереве. | Сборка завершена без ошибок; время записать. |
| 2 | Запустить игру на 3–5 минут: титул → ходьба → диалог → чемодан. | Нет падений, картинка как раньше. |
| 3 | `tools/verify.sh` (быстрая проверка). | Зелёная. |
| 4 | Сравнить fps: на сцене ходьбы взять число кадров в секунду до и после (если есть счётчик в меню). | Не хуже прежнего; если есть расхождение — приложить числа. |

**DoD.**
- Сборка и verify зелёные.
- Игра ведёт себя как до смены флагов (общая проверка).
- Время сборки известно и приемлемо автору.

**Что приложить при неудаче.** вывод сборки, версия rustc.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
cargo build --release -p sunpetal-app
tools/verify.sh
tools/qa/play.sh ru   # 3–5 минут: титул → ходьба → диалог → чемодан
```
