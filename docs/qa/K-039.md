# K-039. Автообход глав: ходьба, головоломки, поздние сцены

**Цель.** Проверить автообход (безголовый прогон глав) на нескольких главах и убедиться, что он доходит до позднего состояния.

**Предусловия.**
- ROM и сохранения по `docs/debug-tools.md` (разделы про автоигру); команды — уточнить у ассистента (скрипт обхода из этапа 8б.Г.1).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Запустить автообход на трёх главах: ранней (C02), средней и поздней. | Каждый прогон завершается с отчётом, без падений и зависаний. |
| 2 | В отчёте найти сцены с головоломками. | Головоломки пройдены или честно помечены «не пройдена». |
| 3 | Выборочно открыть 3 снимка из прогона. | Картинка соответствует названию сцены. |

**DoD.**
- Три главы пройдены без падения.
- Список непроходимых мест записан (даже если не пуст).

**Что приложить при неудаче.** лог прогона, номер кадра остановки.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
ROM="$HOME/Developer/games/fsar-ru/roms/Flower, Sun and Rain - Murder and Mystery in Paradise (Europe) (En,Fr,De,Es,It).nds"
cargo build --release -p sunpetal-runtime --bin sunpetal-debug
target/release/sunpetal-debug "$ROM" --save /tmp/work.sav --goto C02_01 --autoplay   # затем средняя и поздняя главы, форма — docs/debug-tools.md
```
