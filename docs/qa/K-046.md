# K-046. Пресеты пропорции: follow_shape, отдельная ширина 3D

**Цель.** Проверить, что в окне разной формы раскладка вписывается, полосы симметричны, касание не смещено.

**Предусловия.**
- Меню приложения (Esc) → видео.
- Пресеты: 16:9, 16:10, 21:9, портрет, свободное (из плана Д.1).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Выбрать каждый пресет по очереди. | Окно принимает форму, картинка DS вписана целиком, пропорции экранов 4:3. |
| 2 | Для каждого пресета: полосы по бокам или сверху/снизу одинаковы. | Симметрично. |
| 3 | Коснуться (мышью) центра нижнего экрана, затем углов. | Курсор игры попадает туда, куда указано; середина = (128, 96). |
| 4 | Режим `follow_shape`: менять размер окна мышью. | Раскладка перестраивается без рывков, 3D не растягивается непропорционально. |
| 5 | Отдельная ширина 3D: менять значение (если есть пункт). | 3D расширяется без искажения персонажей; HUD на месте. |

**DoD.**
- Все пресеты и обе ориентации ПРОШЛИ.
- Любое растяжение или смещение касания — НЕ ПРОШЛО.

**Что приложить при неудаче.** `window_N.png` и `vN.json` по F10, язык, шаг, пресет, размер окна.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
tools/qa/play.sh ru   # Esc → видео → пресеты
```
