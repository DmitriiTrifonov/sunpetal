# K-054. Android: системный диалог выбора файла

**Цель.** Проверить выбор ROM или файла данных через системный диалог.

**Предусловия.**
- Телефон Android с собранным APK (`docs/ANDROID.md`); ROM на устройстве в разных местах (Загрузки, SD, облачная папка).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Первый запуск: нажать «выбрать файл». | Открывается системный диалог SAF. |
| 2 | Выбрать ROM из «Загрузок». | Игра запускается, путь запоминается. |
| 3 | Закрыть приложение, открыть заново. | Игра стартует без повторного выбора (доступ сохранён). |
| 4 | Выбрать неверный файл (txt/zip). | Понятное сообщение об ошибке, приложение не падает. |
| 5 | Отказаться от выбора (назад). | Возврат на стартовый экран без падения. |
| 6 | Выбрать файл из облачной папки (Drive), если есть. | Работает или даёт понятную ошибку. |

**DoD.**
- Шаги 1–5 ПРОШЛИ на реальном телефоне; шаг 6 — как получится, результат записать.

**Что приложить при неудаче.** модель телефона и версия Android, `adb logcat` вокруг ошибки.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
# Android: сборка и установка по docs/ANDROID.md
tools/android/build-apk.sh
adb install -r build/android/sunpetal.apk
adb logcat -c && adb logcat | grep -i sunpetal
```
