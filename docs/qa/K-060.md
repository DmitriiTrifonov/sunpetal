# K-060. Меню «3D рисует», телефон, MSAA в окне

**Цель.** Проверить переключатель движка 3D (софт/GPU), MSAA и поведение на телефоне.

**Предусловия.**
- Сборка с фичей `gpu`; меню приложения (Esc) → «3D рисует».

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Переключить «3D рисует» между вариантами в сцене ходьбы с 3D. | Картинка не отличается заметно (GPU обязан совпадать с софтом); переключение без падения и без чёрного кадра. |
| 2 | Включить MSAA (если есть пункт), проверить кромки на персонаже и фоне. | Кромки сглажены, 2D и текст не размыты, нет полос. |
| 3 | Выключить MSAA. | Возврат к прежней картинке. |
| 4 | Повторить шаги 1–3 на телефоне. | То же; fps приемлем. |
| 5 | Закрыть и открыть игру. | Выбор сохранился. |

**DoD.**
- Шаги 1–5 без падений и артефактов.
- Любое различие софт/GPU — заводится как баг GPU (по правилам проекта).

**Что приложить при неудаче.** `window_N.png` и `vN.json` по F10, язык, шаг, вариант настроек, GPU.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
tools/qa/play.sh ru --renderer gpu   # софт: --renderer software; переключатель — Esc → «3D рисует»
```
