# K-092. Манифест pack.toml: id текстур

**Цель.** Проверить, что пакет 2D собирается по id, старые имена-ключи работают без манифеста, а одна картинка закрывает несколько ключей.

## Проверено ассистентом (2026-11-08), частично

- Тесты манифеста зелёные (`pack2d::tests::a_manifest_gives_one_picture_to_several_keys`, `a_manifest_folder_serves_every_key_of_an_id`).
- Предусловие не выполнено: в `build/2d-pack-case` нет `pack.toml` и 257 файлов вместо 52; шаги 1, 3, 4 не прогонялись (нужен манифест и каталог из 52 картинок). Шаг 2 за автором.

**Предусловия.**
- Каталог `build/2d-pack-case` (52 картинки) и манифест `pack.toml`.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Собрать пакет генератором. | Сборка без ошибок и предупреждений о потерянных ключах. |
| 2 | Запустить игру, пройти ЖМИ/PUSH-экран и устройство. | Картинки подменены; один файл покрывает все ключи (ЖМИ/PUSH, палитры). |
| 3 | Убрать `pack.toml`, оставить старые имена-ключи. | Игра всё равно подменяет по хэшам. |
| 4 | Выгрузить `index.csv` (`sunpetal-debug dump2d`). | В нём есть колонка id, значения совпадают с манифестом. |

**DoD.**
- Все четыре шага дали ожидаемое.
- Количество подменённых ключей = прежнему (52 картинки → те же ключи).

**Что приложить при неудаче.** вывод генератора, `index.csv`.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
ls build/2d-pack-case | wc -l
# пересборка пакета: sunpetal-pack-2d --merge (параметры — docs/BUILD.md, раздел про пакет 2D)
SUNPETAL_PACK_2D=build/2d-pack-case tools/qa/play.sh ru
target/release/sunpetal-debug dump2d   # index.csv
```
