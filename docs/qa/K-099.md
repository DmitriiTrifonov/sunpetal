# K-099. sunpetal-debug frame <rec> <N>

**Цель.** Проверить, что по записи сеанса и номеру кадра команда достаёт полный разбор кадра.

**Предусловия.**
- Запись сеанса `<rec>` (как создать — `docs/debug-tools.md`); известный номер кадра N.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Выполнить `sunpetal-debug frame <rec> <N>`. | Печатается/сохраняется: `index.csv` 2D, спрайты и слои, снимок окна кадра, регистры. |
| 2 | Взять два разных N (ходьба и диалог). | Содержимое отличается и соответствует кадру. |
| 3 | Взять N за пределами записи. | Понятная ошибка, не падение. |
| 4 | Сверить снимок кадра с F10-снимком того же кадра. | Совпадает. |

**DoD.**
- Шаги 1–4 ПРОШЛИ.
- Вывод достаточен, чтобы ассистент мог разобрать баг по номеру кадра без окна.

**Что приложить при неудаче.** команда и вывод.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
cargo build --release -p sunpetal-runtime --bin sunpetal-debug
target/release/sunpetal-debug frame <rec> <N>   # запись и N — docs/debug-tools.md
```
