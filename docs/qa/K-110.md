# K-110. Модели PS2 2/5: конвертер в секцию MODL

**Цель.** Проверить, что конвертер превращает модели PS2 в секцию `MODL` файла данных, читаемую рантаймом.

**Предусловия.**
- PS2-образы доступны; команда конвертера — уточнить у ассистента.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Запустить конвертер на выбранной модели. | Секция `MODL` добавлена в файл данных, лог без ошибок. |
| 2 | Прочитать её обратно (читатель/тест). | Число вершин и треугольников совпадает с исходной моделью. |
| 3 | Открыть OBJ-выгрузку той же модели. | Форма узнаваема, нет «рваных» полос. |
| 4 | Запустить игру с файлом данных. | Игра стартует, оригинал рисуется как раньше (флаг подмены выключен). |

**DoD.**
- Шаги 1–4 ПРОШЛИ.
- Тесты рантайма зелёные.

**Что приложить при неудаче.** лог конвертера, имя модели.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
python3 tools/ps2/mkmodels.py MANIFEST.json OUTDIR [ИМЯ ...]   # манифест — см. docstring скрипта
python3 -m unittest discover tools/ps2 2>&1 | tail -3
cargo test -p sunpetal-app --release --lib
```
