# K-111. Модели PS2 3/5: подмена на границе GX

> **Оговорка (2026-11-08, K-183…K-185).** Подмена берёт `OP#18` (машина), у которой части модели не на местах (нет матриц частей). Проверку подмены машины отложить до K-185; механизм (флаг, паритет софта и GPU, откат на оригинал) от этого не зависит. Детали — `docs/PS2-MODEL-CHECKS.md`.

**Цель.** Проверить подмену DS-модели моделью PS2 за флагом: софт и GPU совпадают, при сбое рисуется оригинал.

**Предусловия.**
- Флаг подмены включён в конфиге; манифест подмены (K-128); сцена парковки (машина) — уточнить маршрут у ассистента.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Флаг выключен: сцена парковки. | Рисуется оригинал. |
| 2 | Флаг включён, движок «софт». | Машина заменена моделью PS2: размер, ориентация, перед/зад верны. |
| 3 | То же на GPU. | Картинка совпадает с софтом (слово в слово). |
| 4 | Подложить заведомо неверную запись в манифест. | Рисуется оригинал, без падения. |
| 5 | Подъехать/сменить сцену. | Подмена не «залипает» на чужих объектах. |

**DoD.**
- Софт = GPU, сбой = оригинал, флаг по умолчанию выключен.

**Что приложить при неудаче.** `window_N.png` и `vN.json` по F10, язык, шаг, флаг, движок.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
SUNPETAL_PACK_LOG=1 tools/qa/play.sh ru --save build/user.sav --renderer software
# GPU: --renderer gpu; флаг подмены и манифест — в конфиге (см. K-128)
```
