# K-113. Модели PS2 5/5: апскейл и перерисовка DS-ресурсов

**Цель.** Оценить пробный апскейл текстур и лиц с PS2 по сравнению с оригиналом.

**Предусловия.**
- Пакет с пробными ≈12 текстурами и лицами/парами PS2 (`docs/UPSCALE-DS.md`).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Открыть сцены, где есть пробные текстуры (список в `docs/UPSCALE-DS.md`). | Подмена видна, швов на границах нет. |
| 2 | Сравнить с оригиналом (пакет выключить). | Детали чётче, цвета не уплыли, пропорции совпадают. |
| 3 | Лица (портрет в диалоге 64×64): сравнить 5 портретов. | Лица узнаваемы и соответствуют персонажу. |
| 4 | Для каждой оценить: принять / переделать. | Таблица оценок. |

**DoD.**
- Таблица оценок заполнена по всем пробным.
- По отклонённым — причина.

**Что приложить при неудаче.** `window_N.png` и `vN.json` по F10, язык, шаг, ключ текстуры.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
SUNPETAL_PACK_2D=build/2d-pack-case tools/qa/play.sh ru --save build/user.sav
# для сравнения без пакета: tools/qa/play.sh ru --save build/user.sav
```
