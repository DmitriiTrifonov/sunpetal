# K-114. Форматирование и clippy

**Цель.** Проверить, что fmt/clippy строгие и CI зелёный.

**Предусловия.**
- Чистое рабочее дерево после коммита; нет открытых worktree исполнителей.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | `cargo fmt --all --check`. | Без вывода, код 0. |
| 2 | `cargo clippy --all-targets -- -D warnings` (по проекту). | Без замечаний. |
| 3 | `STRICT=1 tools/verify.sh`. | Зелёная. |
| 4 | Открыть CI на GitHub. | Job lint без `continue-on-error`, зелёный. |

**DoD.**
- Все четыре шага зелёные.

**Что приложить при неудаче.** вывод команды.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
cargo fmt --all --check
cargo clippy --all-targets -- -D warnings
STRICT=1 tools/verify.sh
```
