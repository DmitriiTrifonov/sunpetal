# K-118. Пакет 2D: значки меню ходьбы

**Цель.** Проверить подменённые значки чемодана и карточки, счётчик шагов и стрелку возврата.

**Предусловия.**
- Пакет собран; игра на ходьбе C02_01 (`--goto C02_01 --autoplay`).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Нажать START на ходьбе (меню ходьбы). | Значки слева: чемодан и карточка перерисованы. |
| 2 | Счётчик шагов (значок «018»). | Цифры читаются, число меняется при ходьбе. |
| 3 | Стрелка возврата (внизу справа). | Перерисована, нажимается. |
| 4 | Тап по чемодану. | Открывается устройство (не сломана геометрия нажатия). |
| 5 | RU и EN. | Одинаково. |

**DoD.**
- Значки на месте, нажатия работают, оба языка.

**Что приложить при неудаче.** `window_N.png` и `vN.json` по F10, язык, шаг.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
SUNPETAL_PACK_2D=build/2d-pack-case tools/qa/play.sh ru --goto C02_01 --save build/user.sav
# EN: заменить ru на en
```
