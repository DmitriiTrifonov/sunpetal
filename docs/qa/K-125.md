# K-125. Тулинг PS2 2/5: каталог PS2-моделей

**Цель.** Проверить выгрузку всех `.BIN` в OBJ + текстуры + контактный лист.

**Предусловия.**
- `tools/ps2/catalog.py`; образы PS2.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Запустить каталогизацию. | Лог без ошибок, на выходе OBJ, PNG и контактный лист. |
| 2 | Выбрать 10 моделей на листе, открыть OBJ. | Форма совпадает с миниатюрой; серии вершин — полосы (strips), не тройки. |
| 3 | Модели с «мусорными» вершинами (UV ~1e33). | Отфильтрованы, нет улетевших точек. |
| 4 | Сравнить число моделей с числом записей. | Расхождения объяснены. |

**DoD.**
- 10 моделей визуально верны.
- Список пропусков есть.

**Что приложить при неудаче.** имя BIN, номер записи.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
python3 tools/ps2/catalog.py --help
```
