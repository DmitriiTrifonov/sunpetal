# K-126. Тулинг PS2 3/5: каталог DS-объектов по ключу текстуры

**Цель.** Проверить каталог DS-объектов из трассы GX.

**Предусловия.**
- Прогон трассы; инструмент `tools/ps2/dsobjects.py`.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Построить каталог на кадре парковки. | Для каждого объекта: TexKey, число вершин, матрицы, габарит. |
| 2 | Сверить 3 объекта со снимком кадра. | Совпадает по виду и числу. |
| 3 | Запустить тест (`tools/ps2/test_dsobjects.py`). | Зелёный. |

**DoD.**
- Каталог строится и совпадает со снимком.

**Что приложить при неудаче.** кадр, TexKey.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
python3 tools/ps2/dsobjects.py --help
python3 tools/ps2/test_dsobjects.py
```
