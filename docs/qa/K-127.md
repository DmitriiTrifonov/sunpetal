# K-127. Тулинг PS2 4/5: автосопоставление DS↔PS2

**Цель.** Проверить автоподбор пары и ориентации.

**Предусловия.**
- Каталоги K-125 и K-126; `tools/ps2/orient.py`.

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Запустить сопоставление на машине парковки. | Нашёл перестановку осей (0,2,1) и знаки (−1,1,1). |
| 2 | Проверить масштаб. | Отмечено, что масштаб завышается (0.0623 против 0.032): принять как известное ограничение. |
| 3 | Перед/зад. | Не различаются автоматически; решается по виду из камеры. |
| 4 | Сопоставить ещё 2 объекта. | Результат разумный или явно помечен «нет пары». |

**DoD.**
- Шаги 1–4 выполнены; ограничения записаны.

**Что приложить при неудаче.** вывод orient.py.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
python3 tools/ps2/orient.py --help
python3 tools/ps2/test_orient.py
```
