# K-128. Тулинг PS2 5/5: манифест подмены с горячей перезагрузкой

> **Оговорка (2026-11-08, K-183…K-185).** Записи манифеста, указывающие на машину или мотоцикл PS2, дадут неверную модель, пока части не расставлены (нет матриц частей). Горячую перезагрузку проверять на любой модели, но форму машины оценивать после K-185; детали — `docs/PS2-MODEL-CHECKS.md`.

**Цель.** Проверить, что правка манифеста меняет кадр без перезапуска.

**Предусловия.**
- Игра запущена на сцене с подменяемым объектом; манифест JSON (ключ DS, запись PS2, оси, масштаб).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | Изменить масштаб в манифесте и сохранить. | Через секунду размер в игре меняется. |
| 2 | Изменить оси. | Ориентация меняется. |
| 3 | Испортить JSON. | Сообщение об ошибке в stderr, игра рисует прежнее/оригинал, не падает. |
| 4 | Исправить JSON. | Подмена возвращается. |

**DoD.**
- Горячая перезагрузка работает в обе стороны, битый файл безопасен.

**Что приложить при неудаче.** манифест, stderr.

**Запуск** (из корня репозитория; окно не трогается, если уже открыто).

```sh
SUNPETAL_PACK_LOG=1 tools/qa/play.sh ru --save build/user.sav
# манифест править во втором терминале; формат — tools/ps2/swapman.py --help
```
