# K-140: цифры набора, вариант upscaled (проверка автора)

Генератор `artifacts/2d-samples/redraw/case2/make_digits.py` (не в git): теперь не размытие ×4, а трассировка: ×16, размытие, порог, potrace, отрисовка ×4 со сглаживанием. Файлы `obj0_*@digits.upscaled.png` пересобраны в `build/2d-pack-case`; окно подхватывает пакет само (горячая перезагрузка).

1. Меню → «Цифры устройства» → вариант upscaled. Открыть головоломку с диском (окно набора с цифрой).
2. Цифры 0–9: края ровные, штрихи не толще оригинала, без «ступенек» и неровных пятен. Сравнить с вариантом «оригинал (пиксельные)».
3. Цифра лежит по центру круглого окна, чёрный круг вокруг неё без зазоров.

Результат: `K-140: ПРОШЛО | НЕ ПРОШЛО | НЕ ПРОВЕРЕНО`, снимок F10. Контрольный лист цифр: `artifacts/2d-samples/redraw/case2/digits/upscaled/`.
