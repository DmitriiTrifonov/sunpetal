# K-158. Файл данных отдельно от пакета текстур

**Цель.** Пакет, где только текстуры (`texture_pack`), не останавливает игру при `--lang ru`; перевод берётся из отдельного файла (`--data`, `game.data`). Коммиты c2a73e5, 0b5f212; описание — `docs/BUILD.md`.

**Предусловия.**
- Свежая сборка `cargo build --release -p sunpetal-app`, окно игры закрыто.
- Пакет только с текстурами (например `build/k001.spdata`, если нет — любой `build/game*.spdata` без TRAN) и файл с переводом (`build/9b/full-ru.data`).
- Свой конфиг копируйте в `build/qa-config`, пользовательский не трогайте (так делает `tools/qa/play.sh`).

**Шаги и ожидаемое.**

| № | Действие | Ожидаемо |
|---|---|---|
| 1 | В конфиге `texture_pack` = пакет только с текстурами, `game.data` пусто; запуск с `--lang ru`. | Окна «Игра остановлена» нет; в логе предупреждение про отсутствие переводов; текст английский (из ROM). |
| 2 | То же, но `--data build/9b/full-ru.data`. | Текст русский, текстуры из пакета. |
| 3 | Вместо флага: `game.data` = `full-ru.data` в конфиге. | Как в шаге 2. |
| 4 | Старый конфиг: `texture_pack` = полный `.data` с ROM и переводом, `game.data` нет. | Игра запускается с переводом (миграция), без предупреждения про «нет переводов». |
| 5 | Выбор файла в меню приложения (если есть пункт): выбрать пакет без TRAN, затем файл с переводом. | Первый не останавливает игру; второй даёт перевод после перезапуска (restart_args несёт `--data`). |
| 6 | Общая проверка из README. | Без регрессий. |

**DoD.** Шаги 1–5 ПРОШЛИ; в логе при шаге 1 есть предупреждение, но нет остановки игры.

**Что приложить при неудаче.** `config.toml` (копия из `build/qa-config`), лог запуска, `window_N.png`.

**Запуск.**

```sh
tools/qa/play.sh ru           # шаги 2–3 (там уже подставлен файл данных)
# шаг 1: свой config.toml в build/qa-config, запуск sunpetal-app --lang ru вручную (уточнить)
```
