# K-162. Нативный скриптовый движок 3/6: наблюдатель

**Цель.** Нативный интерпретатор идёт рядом с игрой и не находит расхождений между порядком команд игры и текстом сценариев. Игру он не меняет: выключен по умолчанию (`SUNPETAL_SCRIPT_OBSERVER=1`).

## Уже проверено ассистентом (2026-11-07)

- Без окна, командой REPL `scriptcheck` и `scriptlive` (`docs/NATIVE-SCRIPT.md` п. 9): сцены `Cnn_01` глав 1–18 по 30 000 кадров, расхождений нет; C12_01→C12_03 и C16_01→C16_LIST подхвачены; события с `CHANGEBYVALUE` (C10_27, C14_53, C11_05) — расхождений нет.
- Тесты: `cargo test -p sunpetal-runtime --lib scriptvm` 6 OK.

## Ваша часть

1. Запустить окно с `SUNPETAL_SCRIPT_OBSERVER=1` (по скиллу `window-restart`, лог в `build/qa-app.log`), пройти в игре минут десять: диалоги, ходьба, смена карты, одна-две головоломки.
2. `grep "script observer" build/qa-app.log`: ожидается только сводка «N commands agreed … 0 mismatches» раз в 1800 кадров, без строк `vblank N: …`.
3. Игра ведёт себя как раньше: скорость и звук те же (наблюдатель берёт один поиск по таблице на вход в функцию).

DoD: шаги 1–3 ПРОШЛИ; в «Что приложить»: `build/qa-app.log` (строки `script observer`) и, если расхождения были, `v*.json` ближайшего кадра.
