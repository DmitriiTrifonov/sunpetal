# K-207: списки меню стрелками `< значение >` (проверка автора)

Все 22 выпадающих списка меню заменены на `Spin` (`ui.rs`): `[<] значение [>] подпись`, без попапа. Значение — фокусируемая плитка фиксированной ширины, `<` и `>` — оранжевые метки. Порядок значений тот же, что был в списках. Выбранная плитка теперь синяя с белым текстом (читаемость, K-021).

1. Меню (F1 или START): геймпад вниз/вверх переходит по строкам (на списке одна остановка, метки `<` `>` не фокусируются). Влево/вправо меняют значение, на краях идут по кругу (после последнего первое).
2. Мышь: клик по `<` и `>` переключает на соседнее значение; боковая прокрутка (тачпад) над списком тоже.
3. Клавиатура: Tab к списку, стрелки влево/вправо.
4. Проверить несколько: «Раскладка экранов» (применяется сразу), «Размер окна», «Шрифт реплик», «Графика» (F12-пара), «Пресет (F6)» (меняет сразу все эффекты), «Язык».
5. Длинные значения помещаются («один экран и панель»), плитка не меняет ширину.

Результат: `K-207: ПРОШЛО | НЕ ПРОШЛО | НЕ ПРОВЕРЕНО`, снимок F10. Снимок для сверки: `artifacts/k021/spin3c.png`.
