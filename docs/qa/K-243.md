# K-243: анимации комнат PS2 — убежища C13, грядки C15_08..10, генератор C13_06 (первые клипы)

Окно с PS2 (`SUNPETAL_ULT_MODELS`, `SUNPETAL_EE_EXPORT`), графика «Ультимативный». События по сцене DS (`data/ult/room_events.json`, из `sunpetal-ee` Y-45).

1. Убежища C13_12…C13_17 (карта 3, капсулы): когда DS открывает убежище, у капсулы PS2 открываются две створки (первый клип, режим 1).
2. Грядки C15_08, C15_09, C15_10 (карты 16, 64, 65): две части объекта двигаются плавно.
3. Генератор C13_06 (карты 11 и 83): первый клип играет.
4. Ничего не двигается в других сценах на этих картах.
5. Если створки не двигаются или прыгают, пришлите `where` и скрин.

6. (K-245) Убежища C13_12…17: после реплики и кнопки, когда DS играет второй `STAGEANIMATION` (режим 3), у капсулы PS2 играет второй клип (створки закрываются/меняются), а не остаются открытыми после первого.

Известно: скрытие генератора C13_06 через 60 кадров не сделано. Автоматически дойти до C13_12 `--goto` нельзя (нет пути по дверям с карты 28 на 3): проверено только, что хук считает вызовы `STAGEANIMATION` (C07_33: 1), второй клип в игре глазами не смотрелся.
