# ТЗ тестировщика: проверки автора (колонка «Проверка»)

Файлы `K-NNN.md` — по одной карточке. Дата составления 2026-11-05. Содержание шагов взято из карточек, `docs/BUGS.md` и документов; там, где я не знаю точной процедуры, это помечено «(уточнить)».

## Общее для всех проверок

- Сборка: `cargo build --release -p sunpetal-app`, запуск по скиллу `window-restart` (`--lang ru` или `--lang en`). Проверка идёт **на свежей сборке из рабочего дерева** (оно не закоммичено).
- Снимки: F10 в окне кладёт `artifacts/shots/window_N.png` (окно), `vN.png` (оба экрана DS), `vN.json` (состояние кадра). Прикладывать `window_N.png` и `vN.json`.
- Файл данных: пакет 2D собирается `sunpetal-pack-2d --merge` из `build/2d-pack-case` (ключи `bgNN_<16hex>.png`); если в проверке сказано «пакет», убедитесь, что `pack_2d` в конфиге указывает на него.
- Языки: проверять RU и EN, где в карточке сказано.
- Результат записывать так: `K-NNN: ПРОШЛО | НЕ ПРОШЛО | НЕ ПРОВЕРЕНО`, номер шага, снимок. «НЕ ПРОШЛО» заводится как `Баг: …` (скилл `bug-task`).
- DoD карточки: все шаги дали ожидаемое на обоих языках, где требуется, нет регрессий в «Общей проверке» ниже. Только после этого карточку двигают в «Готово».

## Общая проверка (10 минут, после любой правки окна)

1. Старт игры: логотипы, титул, «Press START».
2. Новая игра или Continue: дойти до ходьбы, открыть меню (START), чемодан, вернуться.
3. Один диалог: текст читаем, плашка не мигает.
4. Закрыть окно: процесс завершён (`pgrep -fl sunpetal-app` пусто).
